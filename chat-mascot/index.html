Integration

Add it to your app

Copy chat-mascot.js into your project. It defines <chat-mascot>, which works in plain HTML, React, Vue, Svelte or anything else that renders DOM.

Markup 
<script type="module" src="/chat-mascot.js"></script>

<button class="ai-chat-button" aria-label="Open AI chat">
  <chat-mascot compact follow-pointer></chat-mascot>
</button>
Wiring it to your chat 
const fish = document.querySelector('chat-mascot');

button.onpointerenter = () => fish.react('excited', 900);
button.onclick = () => fish.play('dash');

async function ask(question) {
  fish.mood = 'thinking';
  try {
    for await (const chunk of streamReply(question)) {
      fish.mood = 'talking';
      render(chunk);
    }
    fish.mood = 'idle';
    fish.react('happy', 1500);
  } catch {
    fish.mood = 'idle';
    fish.react('sad', 2500);
  }
}
  • mood sets a lasting state. react(mood, ms) shows a mood briefly, then returns to the previous one.
  • play(name) runs wiggle, jump, spin, dash or nod once, on top of the current mood.
  • Use compact at 72px and below. It frames the head tighter and enlarges the face so expressions stay readable.
  • The fish is decorative (aria-hidden), so give the button its own aria-label. Motion stops when the viewer has reduced motion turned on.
  • Restyle the face and effects with --mascot-ink and --mascot-accent.
