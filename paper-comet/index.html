A paper comet bot that reacts while the AI works

The logo's comet, folded into a little robot: a paper head with a glowing screen face, an antenna light that pulses faster the harder it works, a paper ring that orbits while it thinks, and ribbon tails that trail behind every move. Each mood has its own face and body position, and its eyes follow the cursor.

Integration

Add it to the app

Install three.js, copy paper-comet.js into the project and import it once. It defines <paper-comet>, which works in plain HTML, React, Vue or Svelte.

Setup 
npm install three

// main.js
import './paper-comet.js';

<paper-comet id="comet" follow-pointer
  role="button" tabindex="0"
  aria-label="Open Ask AI"
  style="position: fixed; right: 12px;
         bottom: 12px; width: 170px">
</paper-comet>
Wiring it to Ask AI 
const comet = document.getElementById('comet');

comet.onpointerenter = () => comet.react('excited', 900);
comet.onclick = () => { comet.play('loop'); openAskAI(); };

async function ask(prompt) {
  comet.mood = 'thinking';
  try {
    for await (const chunk of streamReply(prompt)) {
      comet.mood = 'talking';
      render(chunk);
    }
    comet.mood = 'idle';
    comet.react('happy', 1500);
  } catch {
    comet.mood = 'idle';
    comet.react('sad', 2500);
  }
}

onExportStart(() => (comet.mood = 'launch'));
onExportDone(() => { comet.mood = 'idle'; comet.play('loop'); });
  • mood sets a lasting state: a face, a body position and the antenna light's rhythm. react(mood, ms) shows a mood briefly, then returns to the previous one.
  • play(name) runs loop, spin, flip, swoop, dash, jump, wiggle or nod once, on top of the current mood.
  • Add rotatable to let people drag it around in 3D, or call rotateTo(yaw, pitch). Either way it eases back to its resting view.
  • The background is transparent, so the comet and its soft shadow sit on the app. Size it with CSS width; 150 to 200px works well in a corner. It stops rendering while off screen or in a background tab, and holds still for people who turn on reduced motion.
  • When the comet is the control, give it role="button", tabindex="0" and an aria-label, and handle Enter and Space as well as clicks.
